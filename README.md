# codealpha-internship-tasks
This repository contains the projects completed as part of my CodeAlpha Python Programming Internship.
Each task is a separate Python project designed to practice different programming concepts through simple, practical applications.

📌 Tasks Included

🎯 Task 1: Hangman Game

A simple text-based Hangman Game where the player guesses a hidden word one letter at a time.

Features:

-Uses a small list of 5 predefined words.

-Allows the player to guess letters.

-Displays the progress of the hidden word.

-Limits the number of incorrect guesses.

-Runs completely in the console.

Key Concepts:

-Random selection

-while loops

-if-else statements

-Strings

-Lists

-User input and output

📈 Task 2: Stock Portfolio Tracker

A simple Stock Portfolio Tracker that calculates the total investment value based on manually entered stocks and quantities.

Features:

-Allows the user to enter stock names and quantities.

-Uses a predefined dictionary containing stock prices.

-Calculates the total investment value.

-Displays the portfolio information.

-Supports saving the result to a .txt or .csv file (optional).

Key Concepts:

-Dictionaries

-User input and output

-Basic arithmetic

-File handling

💬 Task 4: Basic Chatbot

A simple rule-based chatbot that responds to common user messages.

Features:

-Accepts messages from the user.

-Recognizes basic greetings and common phrases.

-Provides predefined responses.

-Uses simple rules instead of AI or machine learning.

-Runs through the console.

Example Inputs:

-hello

-how are you

-bye

Key Concepts:

-if-elif-else statements

-Functions

-Loops

-User input and output

-String handling

🛠️ Technologies Used

-Python 3

-Python built-in modules and features

-Console-based input/output

📚 Learning Outcomes

Through these tasks, I practiced:

-Python fundamentals

-Working with lists and dictionaries

-Conditional statements

-Loops and functions

-User input and output

-Basic file handling

-Building simple console-based applications

-Applying Python concepts to practical problems
